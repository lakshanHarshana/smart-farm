## Repository Note

This repository does not include the `node_modules` directory because
it significantly increases the project size and contains automatically generated dependency files.

To keep the repository lightweight and follow GitHub best practices, the ` node_modules ` folder has been excluded using  ` .gitignore `.

After cloning the project, install all required dependencies by running:

bash  -->  " npm install "

This command will automatically download and recreate the `node_modules` directory based on the dependencies specified in `package.json`.

**Note:** 
The original completed project is larger in size due to the included dependencies. 
All source code and configuration files required to run the project are available in this repository.
